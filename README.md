# Mayank — Professional Portfolio

A dark, responsive portfolio focused on performance marketing, paid media, analytics, AI tools, n8n automation, Frappe/ERPNext and web projects.

## Sections
- Performance marketing highlights for US and India WhatsApp lead-generation campaigns
- Google Ads, Meta Ads, Google Analytics, Search Console, SEO and Google Business Profile
- AI tools and workflow automation
- ERP workflow demo, chatbot and quotation automation project summaries
- WordPress, HTML/CSS, Canva and digital project work
- Education and certifications

## Privacy choices
- Display name: Mayank only
- No phone number displayed
- No employer names displayed
- No resume download button
- Email is accessed through Contact Me links, not displayed as visible page text
- Education institution displayed as CCSU University

## Files
- `index.html` — portfolio homepage
- `styles.css` — responsive dark theme and animations
- `erp-demo/index.html` — standalone interactive ERP workflow preview with back-to-portfolio links

## ERP demo disclosure
The current `erp-demo/index.html` is a lightweight portfolio preview describing ERP modules and role-based workflow concepts. It is not the full contents of the uploaded ERP ZIP. The full static ERP project should be copied into `erp-demo/` before claiming the original complete demo is hosted. No live backend, database or real authentication is provided by the preview.
