# Mayank — Professional Portfolio

Live portfolio: https://mayank-digital.github.io/

A responsive, dark portfolio focused on performance marketing, paid media, analytics, AI-enabled automation, Frappe/ERPNext and web projects.

## Highlights
- Performance marketing results for US and India WhatsApp lead-generation campaigns
- Google Ads, Meta Ads, Google Analytics, Search Console, SEO and Google Business Profile
- AI tools, n8n workflow automation and chatbot projects
- Original ERP demo with Sales, Accounts, Dispatch/Stock, HR and related workflows
- WordPress, HTML/CSS, Canva and digital marketing projects

## Privacy choices
- Display name: Mayank only
- No phone number displayed
- Employer names omitted
- No resume download button
- Email address is available through Contact Me buttons only
- Education institution displayed as CCSU University

## Key files
- `index.html` — portfolio homepage
- `styles.css` — responsive dark theme and animations
- `erp-demo/index.html` — original interactive ERP demo entry point
- `erp-demo/css/`, `erp-demo/js/`, `erp-demo/data/` — ERP styles, application logic and sample data

## ERP demo disclosure
The ERP demo is a static browser-based demonstration with sample data. It does not connect to a production backend or database, and demo actions do not persist data. See `erp-demo/README.md` and `erp-demo/FEATURES.md` for details.
